# house

브라우저에서 플레이하는 작은 2D 숲속 생활형 RPG 프로토타입입니다. 따뜻한 동화풍 일러스트와 게임 화면 안의 최소 UI를 사용합니다.

## 바로 실행

`play.html`을 다운로드한 뒤 브라우저로 열면 서버나 인터넷 연결 없이 플레이할 수 있습니다.

## 기능

- WASD 이동, 집·나무·연못 충돌, 맵 경계 제한
- NPC 근처에서 E로 대화, 대화 중 이동 정지
- 집 입구에서 E로 입장
- 실내 Chair/Table 선택 후 바닥 클릭으로 배치
- 가구 클릭으로 선택, Delete로 삭제
- 실내 나가기 버튼으로 야외 복귀

가구는 집 왕복 시 유지되며 새로고침하면 초기화됩니다. 인벤토리나 영구 저장 기능은 없습니다.

## 개발

Node.js 20.19 이상을 권장합니다.

```sh
npm install
npm run dev
```

개발 주소: http://127.0.0.1:5174

```sh
npm test
npm run build
```

빌드하면 `dist/`와 단일 실행 파일 `play.html`이 생성됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/world.js` | 맵·장애물·NPC 데이터 |
| `src/state.js` | 게임 상태·이동·충돌 |
| `src/input.js` | 키보드 입력 |
| `src/dialogue.js` | 근접 판정·대화 상태 |
| `src/decoration.js` | 집 출입·가구 배치·선택·삭제 |
| `src/renderer.js` | 야외 렌더링 |
| `src/scenery.js`, `src/art.js` | 숲 배경·일러스트 도구 |
| `src/roomRenderer.js` | 집 내부 렌더링 |
| `src/main.jsx`, `src/style.css` | 게임 루프·화면 내 UI |
| `tests/` | 이동·충돌·대화·꾸미기 검사 |

## 수동 확인

1. WASD로 이동하고 집·나무·연못·화면 경계를 통과하지 않는지 확인합니다.
2. NPC에게 접근한 뒤 E를 눌러 대화합니다. 대화 중에는 이동하지 않아야 합니다. ESC로 닫습니다.
3. 왼쪽 집의 아래 문 앞에서 E로 입장합니다.
4. Chair/Table 버튼 → 바닥 클릭 → 가구 클릭 → Delete 순서로 배치·선택·삭제를 확인합니다.
5. 집 밖으로 나갔다 다시 들어와 남은 가구가 유지되는지 확인합니다.
