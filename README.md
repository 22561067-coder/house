# house · 토끼의 숲

살구빛 종이 바닥, 이끼색 식물, 적갈색 윤곽선의 동화풍 공간 꾸미기 게임입니다.

**[게임 실행](https://22561067-coder.github.io/house/play.html)**

## 꾸미기

- 아래 선반에서 나무·버섯·꽃·고사리·클로버·돌·통나무·바구니·찻상·등불·토끼를 선택한 뒤 공간을 클릭해 배치합니다.
- 화살표 도구는 선택 모드입니다. 물건을 클릭해 선택하고 드래그해 옮깁니다.
- 선택 후 Delete 또는 휴지통 버튼으로 삭제합니다. 나무와 자연물을 포함해 모든 배치물이 편집 대상입니다.
- 선택 도구 옆 편집 버튼으로 크기와 좌우 방향을 바꿀 수 있습니다.
- Ctrl+Z로 되돌리기, Ctrl+Shift+Z로 다시 하기, ESC로 선택 취소가 가능합니다.
- 아래 선반의 작은 화살표로 도구를 접거나 펼칩니다. 작은 화면에서는 선반을 가로로 스크롤합니다.

## 토끼와 모션

캐릭터는 토끼 한 마리입니다. 토끼는 돌아다니지 않고 제자리에서 숨쉬기·눈 깜빡임·귀 기울이기·코 킁킁 모션을 보입니다. 토끼를 클릭하면 앞발을 들어 반응합니다. 토끼도 배치하거나 삭제할 수 있으며, 이미 있는 상태에서 토끼를 배치하면 복제 대신 위치를 옮깁니다.

나무와 식물은 아주 작게 흔들리고 등불은 은은하게 빛납니다. 배치 시 살짝 튀어 오르는 모션과 작은 반짝임, 삭제 시 사라지는 입자가 표시됩니다. 앞뒤 순서는 배치한 바닥 위치에 따라 자연스럽게 달라집니다.

영구 저장과 인벤토리는 없습니다. 새로고침하면 기본 구성이 돌아옵니다. 이전 마을 이동·NPC·집 출입은 현재 게임에서 사용하지 않습니다.

## 실행·개발

`play.html`을 다운로드해 브라우저로 열면 오프라인으로 실행됩니다.

Node.js 20.19 이상에서:

```sh
npm install
npm run dev
npm test
npm run build
```

현재 진입점은 `src/main.jsx`이며 `gardenState.js`가 배치 규칙, `gardenRender.js`가 레이어·모션·효과를 담당합니다. `atlasData.js`는 동일 스타일의 그림 16칸을 포함한 내장 이미지입니다. `assets/woodland-atlas.png`는 원본 아트 파일입니다. 기존 마을 관련 파일은 이전 버전 참고용이며 현재 진입점에서 사용하지 않습니다.

## 확인

모든 13종을 배치·선택·이동·삭제해 보고, 나무 뒤와 앞에 소품을 놓아 깊이 순서를 확인합니다. 투명한 부분을 클릭하면 뒤에 있는 물체를 선택합니다. 토끼를 다시 배치해도 한 마리만 남아야 합니다. 배치/삭제 후 되돌리기로 복구할 수 있습니다.
