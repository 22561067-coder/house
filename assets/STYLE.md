# 아트 방향

사용자가 제공한 숲속 꾸미기 참고 이미지의 살구/크림 바닥, 이끼/올리브색 식물, 붉은 황토색 버섯과 적갈색 윤곽선을 기준으로 만들었습니다. 컬러 펜슬/과슈의 거친 질감, 귀여운 데포르메, 사선으로 내려다보는 입체감 있는 형태를 사용합니다.

내장 이미지 생성 도구로 생성한 프로젝트용 투명 스프라이트 아틀라스입니다. 4×4칸: 수양나무, 둥근 나무, 큰 버섯, 작은 버섯 / 들꽃, 고사리, 클로버, 돌 / 통나무, 바구니, 그루터기 찻상, 등불 / 같은 토끼의 기본·눈깜빡임·귀기울임·앞발/킁킁 포즈.

사용 프롬프트 요약: "Production game sprite atlas, regular 4 by 4 grid, each object isolated on transparent background. Strict reference palette and textured colored-pencil/gouache woodland style. Rust reddish-brown outlines, warm peach cream, dark moss and olive foliage, red ochre mushrooms. Elevated three-quarter view, dimensional forms, not flat vector or pixel art. Twelve harmonious nature/prop sprites, four consistent poses of one plump ivory bunny. No other animals, people, buildings, UI, words or grid."
